### Some items of note in C...

All statements end with a `;`  
All keywords are case sensitive

Errors will occur in compiling if syntax is incorrect

#### Escape Sequences

`\n` will give you a new line in a string  
`\t` will tab in a string

`//` denotes a comment  
`/*  */` gives you a block comment that can span multiple lines

#### Compiling C with gcc

`gcc script.c` will create a file called `a.out` 
`gcc script.c -o myProgram` will use the `-o` variable to name the executable file
